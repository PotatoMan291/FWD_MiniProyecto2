# Portal de Recursos Humanos con RAG Multiagente

## Descripción del proyecto

El proyecto consiste en el desarrollo de un portal interno de Recursos Humanos para la empresa ficticia Café Montaña S.A., que implementa inteligencia artificial mediante una arquitectura multiagente y la técnica RAG (Retrieval-Augmented Generation).

Su objetivo es automatizar las consultas de los colaboradores sobre las políticas internas de la empresa, proporcionando respuestas precisas, contextualizadas y respaldadas por documentos almacenados en Google Drive. Asimismo, busca facilitar la gestión de Recursos Humanos mediante la generación automática de reportes e indicadores.

## Funcionalidades principales

- Chat inteligente para consultas de Recursos Humanos.
- Arquitectura basada en cinco agentes especializados.
- Integración y sincronización automática con Google Drive.
- Procesamiento de documentos PDF, Google Docs y Google Sheets.
- Búsqueda semántica mediante embeddings y similitud coseno.
- Generación de respuestas con citas y referencias documentales.
- Autenticación y control de acceso basado en roles.
- Dashboard de indicadores de Recursos Humanos.
- Generación automática de reportes diarios.
- Protección y privacidad de los datos de los colaboradores.

## Tecnologías utilizadas

- **Frontend:** React + Vite.
- **Backend:** Node.js + Express.
- **Base de datos:** MySQL.
- **Inteligencia artificial:** DeepSeek API.
- **Embeddings:** Google Gemini API.
- **Almacenamiento documental:** Google Drive API.
- **Servicios en la nube:** Google Cloud Platform.
- **Autenticación:** JWT.
- **Pruebas:** Postman.
- **Control de versiones:** Git y GitHub.

## Objetivo académico

Este proyecto tiene como finalidad aplicar conocimientos de desarrollo Full Stack, inteligencia artificial generativa, sistemas multiagente, recuperación aumentada de información y gestión de bases de datos, mediante la construcción de una solución empresarial que permita optimizar los procesos internos de Recursos Humanos.
